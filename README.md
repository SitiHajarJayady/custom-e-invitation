# custom-e-invitation

**Role:** Software Developer  
**Company:** Ticket2U Sdn. Bhd.  
**Duration:** 2023 – Present  
**Tech Stack:** VB.NET, SQL Server, HTML, CSS

## Overview

Designed and developed a custom e-invitation page for event participants. The page displays personalized invitation details and integrates QR code functionality for check-in.

## Key Features

- Personalized content based on guest data (e.g., name, event, seat)
- Responsive design for mobile and desktop
- QR code for event check-in

## Contributions

- Developed the frontend layout using HTML and CSS for the invitation page
- Connected backend logic to dynamically generate guest-specific details using VB.NET
- Implemented QR code generation and integrated it into the invitation page
- Ensured responsive design for mobile and desktop devices
- Collaborated with the team to test and deploy the page securely for client use
